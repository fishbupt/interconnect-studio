# PLTS 分析工作台

产品以 Keysight PLTS 的分析流程为参照。界面采用浅色工程主题，保留 PyQt6/pyqtgraph、
现有文件格式、工程/模板、S 参数格式化、Marker、文件导入/导出和后台任务。
本工程不提供独立 S 参数文件比较、A/B 页面或跨文件曲线比较入口。

## 布局与操作

- 无需创建工程即可导入 Touchstone/CITI。
- 左侧为 Data Browser 和 Parameter / Format，主区为文件摘要和 Analysis View 图网格。
  停靠面板可调整、浮动或关闭；长参数表单可滚动。
- 摘要显示当前文件、端口数、频点数、频段和参考阻抗。
- 二端口 Single-End 默认 2×2：上排 S11/S12，下排 S21/S22，点击图框选择当前图。
- 当前文件的参数曲线统一蓝色实线、无采样点标记；图标题区分参数，图例保留曲线名。
- 当前图可手动设 Y 最小/最大，拒绝非有限数及倒置范围。
  全部图 AutoScale 在主区直接可用，当前图 AutoScale、Marker、曲线数据表、CSV/PNG
  和复制图片可从频域菜单操作。
- 分别提供当前图曲线导出和当前文件完整数据导出，避免混淆数据范围。
- 显示范围按参数/格式保留于会话，切换文件窗口后可恢复。工程保存当前范围，
  不保存其他格式的历史范围缓存。
- 底部显示状态和可折叠日志。耗时文件操作继续复用 TaskRunner 与忙碌对话框。

## 状态与兼容

独立比较页、比较按钮、比较菜单、专用比较服务及主动跨文件叠加代码已移除。
旧版多来源工程中的曲线仍可读取、显示和导出；关闭来源时清理依赖曲线与 Marker。
此兼容路径不会增加新的比较操作入口。公共 `.icproj`/模板格式、Network 与数值算法未改动。

窗口几何和停靠状态仍由原 QSettings 命名空间保存；废弃的比较格式和分隔栏设置在退出时清理。
界面主题继续支持浅色/深色，正文约 10 pt，优先微软雅黑，其次 Noto Sans CJK SC、Segoe UI
和系统字体。Linux 建议安装 Noto Sans CJK SC。

## 验证

使用真实 Qt 控件在 Linux 离屏环境检查 1420×900、1000×700 与深色模式，确认没有比较入口，
侧栏操作可达，S11/S12/S21/S22、Marker、手动范围、工程恢复及导出正常。
截图使用项目自带测试数据，不代表实际器件。Windows 高 DPI 和真实仪器未在此环境验证。
