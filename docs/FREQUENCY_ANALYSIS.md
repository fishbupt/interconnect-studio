# 频域分析操作

本轮完善 Cartesian 频域分析：Marker、曲线管理、数据表和结果导出。
单端与平衡频域视图都可使用这些操作。Smith / Polar 仍待独立绘图实现。

## 两端口导入默认布局

两端口文件导入 Frequency Domain（Single-Ended）后，默认建立一个 2×2 分析视图，
每个绘图区一条 Log Mag 曲线；选中左上格。排列如下：

| 左列 | 右列 |
| --- | --- |
| S11 | S12 |
| S21 | S22 |

该默认布局不继承上一个窗口的网格尺寸。其他端口数及其他分析类型沿用原来的默认行为；
之后仍可手动修改网格、添加曲线，保存工程或模板时保留当前布局。

## 使用步骤

1. 导入测量文件，选择窗口和当前格，通过 Parameter / Format 添加参数曲线。
2. 打开「频域分析 → 频域分析 / Marker」停靠面板，选择要操作的曲线。
3. 添加 Marker，逐点移动、指定频率或拖动图中的竖线；查看绝对或 Delta 读数。
4. 调整当前图或全部图的刻度，查看数据表、导出当前图 CSV/PNG 或当前文件完整数据。
5. 保存工程以保留文件、布局、曲线、Marker 和当前刻度。

## Marker

- 每个 plot 独立编号，绑定曲线索引；位置以 Hz 保存，Y 从曲线实时读取。
- 设置频率和拖动均吸附到最近测量点，不插值；超出范围时吸附到端点，等距离选较低频点。
- 「前一点 / 后一点」按测量点移动。在 Marker 下拉框获得焦点时，左右方向键也可逐点移动。
- Min / Max 搜索有限值；Target 寻找最接近目标 Y 的测量值。
  可选择全频段或当前可见频段；同值时选最低频率。
- 当前 Target 不是插值交点搜索；3 dB 带宽搜索尚未实现。
- Delta 可引用当前 plot 中任一绝对 Marker，可跨当前图内的曲线引用。
  ΔX / ΔY 使用双方各自的实际频点和纵轴单位。禁止循环和多级 Delta 引用。
- 绝对读数允许显示 inf / -inf；非有限值的 Delta 显示「—」，搜索不使用非有限值。
- 删除参考 Marker 后，依赖它的 Marker 返回绝对读数。删除曲线同时删除其 Marker，
  重排或重命名曲线不会改变 Marker 对应关系。
- Marker 随窗口切换、网格和工程保存恢复；当前模板尚不保存 Marker。

## 曲线管理与历史工程

- 支持当前图曲线重命名、删除与绘制顺序调整。
- 图例保留曲线名，分析面板显示曲线来源。
- 本工程不提供独立 S 参数文件比较、A/B 页或跨文件曲线比较入口。
- 旧工程中的多来源曲线仍可读取、显示和导出，保留原来源 ID 与计算配方。
  关闭来源文件后移除依赖曲线和 Marker，避免显示失去来源的数据。
- 含外部来源曲线的历史窗口仍须保存为工程，单数据来源模板不接受它们。

## 数据与图片导出

| 入口 | 输出内容 |
| --- | --- |
| 曲线数据表 | 当前图全部曲线的实际 X/Y、单位与来源，使用虚拟表格，不复制全部数组 |
| 复制选中单元格 | TSV；离散单元格之间的未选列为空 |
| 导出当前图全部曲线 CSV | UTF-8 BOM 长表：Trace / Source ID / Source / X / X Unit / Y / Y Unit |
| 导出当前图 PNG | 坐标轴、标题、图例、曲线和 Marker；宽度 320～4096 像素，保持比例 |
| 复制当前图到剪贴板 | 1920 像素宽的图像 |

CSV 使用每条曲线独立的 X 列，保留不一致的频点，不为凑表格而插值。
它导出的是当前显示量（如 dB、相位、时延、阻抗），与 File 菜单中的完整 S 矩阵导出不同。
写入后台执行，并原子替换文件；覆盖确认针对最终 `.csv` / `.png` 路径。
数据查看和导出不标记工程已修改；Marker、曲线和缩放操作会标记修改。

## 工程兼容性

新工程使用 `.icproj` v2，增加 plot Marker 和跨文件 Trace 引用。
v2 要求 Trace 来源为工程中存在的文件；读取仍支持 v1，无 Marker 的旧 plot 按空 Marker 恢复。
旧版本软件不支持 v2，明确拒绝读取，避免恢复时静默丢失 Marker 或曲线来源状态。
底层 ZIP / JSON / NumPy 数组布局和容量边界沿用文件流程约定。

## PLTS 分析工作台

主区显示当前文件摘要与 Analysis View 图网格，左侧是 Data Browser 和 Parameter / Format。
保留当前图数据表、CSV/PNG、复制图片、Marker、刻度与文件完整数据导出。
手动 Y 范围须有限且最小值小于最大值；会话内按参数/格式保留历史范围，切换窗口后也可恢复。
工程文件只保存当前显示的范围，历史格式范围不写入工程。

界面使用浅色工程主题并支持深色，所有功能入口围绕当前分析视图。
独立文件比较代码已移除，旧比较设置在保存用户设置时清理。
详情见 [ENGINEERING_GUI.md](ENGINEERING_GUI.md)。
